Sequence Memory Test: Remember the Order, Not Just the Pads

Repeating a growing pattern of lights is one of the oldest memory games around. The electronic game Simon made it famous in the late 1970s. In this version, nine pads light up in a sequence and you tap them back in the same order. Each level adds a step, and your level is your score.

How a round works

  1. Press “Start Sequence Game” and watch the pads light up.
  2. When the pattern ends, tap the same pads in the same order.
  3. If you are right, the next level adds one more step. If you make a mistake, the run ends.

What it exercises

This is a visual and spatial working-memory task: you hold a short series of positions in mind and repeat it in order. It is not the same as the card-matching memory game, where the challenge is remembering where pairs are hidden. Here the challenge is the order of the steps.

Strategies that help

  • Chunk the steps. Group them in twos or threes instead of holding each one separately.
  • Trace a shape. Think of the pattern as a path across the grid.
  • Name the positions. Silently saying “top-left, centre, bottom-right” gives you a second memory trail.
  • Do not rush. Wait for the pattern to finish before you start tapping.

Common questions

Why do I keep failing at the same level?

Longer sequences stop fitting in working memory unless you chunk them. Try grouping the steps into pairs.

Do scores vary from day to day?

Yes. Sleep, stress and distractions all matter, so compare yourself with your own earlier runs.

Will this improve my memory?

Practice improves the game itself. Whether it carries over to everyday memory is still debated, so enjoy it as a warm-up.
